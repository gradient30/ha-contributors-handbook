# 行为准则 {#code-of-conduct}
Home Assistant 是由来自世界各地、具有各种背景和经验水平的人共同构建的。[Home Assistant 行为准则](https://www.home-assistant.io/code_of_conduct/)确保每个人都可以在没有骚扰的情况下参与。通过贡献，你同意遵守该准则。

## 适用范围 {#where-it-applies}
我们共同工作的所有地方：GitHub、[Discord](https://www.home-assistant.io/join-chat/)、[社区论坛](https://community.home-assistant.io/)、社交媒体和活动。当有人在公共场合代表项目时，比如在官方账户或活动中，也同样适用。

## 我们的期望 {#what-we-expect}
- 友善并表现出同理心。
- 尊重与你不同的意见、观点和经历。
- 提供建设性反馈，并优雅地接受反馈。
- 对自己的错误负责任，向受影响的人道歉并从中学习。
- 专注于对社区最有利的事情，而不仅仅是对自己。

## 什么是不可以的 {#what-isnt-okay}
- 性化的语言或图像，以及任何形式的性关注或骚扰
- 钓鱼、侮辱以及个人或政治攻击
- 公共或私下的骚扰行为
- 未经允许分享他人的私人信息，如地址
- 任何其他在专业环境中合理被认为是不适当的行为

## 报告问题 {#reporting-a-problem}
如果你遇到或看到不妥之事，请报告。发送邮件至 [safety@home-assistant.io](mailto:safety@home-assistant.io)，或使用你所在平台的报告或标记功能。每一份报告都会得到审查和调查，处理迅速且公平，并且会尊重报告人的隐私。各个平台如何处理报告，以及版主如何处理报告，请参见 [报告问题](/community/guides/reporting) 和 [版主管理](/community/guides/moderation)。

## 然后会发生什么 {#what-happens-then}
社区负责人会根据影响决定相应的后果。这些后果可能包括私人书面警告、正式警告、临时禁令，甚至对严重违规行为的长期禁令。负责人也可以删除或编辑不符合行为准则的评论、代码、问题及其他贡献内容。

[完整行为准则](https://www.home-assistant.io/code_of_conduct/) 包含每一步的详细信息。该准则基于 [贡献者契约](https://www.contributor-covenant.org/version/2/0/code_of_conduct/) 2.0 版本进行改编。
