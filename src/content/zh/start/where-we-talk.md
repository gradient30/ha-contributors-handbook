# 我们在哪里交流 {#where-we-talk}
Home Assistant 有几个供人们交流的地方。每个地方擅长的方向不同。选择正确的地方可以让你更快得到答案，并且让对话内容日后仍能被其他人找到。

## 简明版 {#the-short-version}
| 你想要 | 去哪里 |
| --- | --- |
| 提问快速问题，或结识其他贡献者 | [Discord](https://www.home-assistant.io/join-chat/) |
| 获取自己环境的帮助 | [社区论坛](https://community.home-assistant.io/) |
| 报告 bug | 在 GitHub 上正确仓库的问题追踪。参见 [报告 bug](/start/report-a-bug) |
| 建议功能 | GitHub 上的 [功能请求](https://github.com/home-assistant/feature-requests/discussions) |
| 讨论 Home Assistant 的构建方式 | GitHub 上的 [架构讨论](https://github.com/home-assistant/architecture/discussions) |
| 询问具体变更 | 问题或 pull request 本身 |
| 参加社区同步会议 | [活动日历](/community/reference/events) |

## Discord {#discord}
[Home Assistant Discord](https://www.home-assistant.io/join-chat/) 是贡献者实时聊天的地方。这里是询问“我从哪里开始？”或“这是个好主意吗？”的最快方式，也是认识项目背后人员的途径。

贡献者频道在你选择角色之前是隐藏的。在侧边栏中选择 **频道和角色**，然后选择适合你所做工作的角色。例如：

- **我想为 Home Assistant 提供开发技能** 会赋予你开发者角色。这会打开 [**#developers**](https://discord.com/channels/330944238910963714/554842238073700352) 频道以及其他开发相关频道。
- 设计师在 [**#designers**](https://discord.com/channels/330944238910963714/1463606665311158284) 聚会。[这个链接](https://www.home-assistant.io/join-chat-design) 直接带你过去。
- 测试 Beta 的人聚集在 [**#beta**](https://discord.com/channels/330944238910963714/427516175237382144)。

贡献者频道如下：| 频道 | 用途 |
| --- | --- |
| [**#developers**](https://discord.com/channels/330944238910963714/554842238073700352) | 一般开发 |
| [**#core**](https://discord.com/channels/330944238910963714/1475552721515053268) | 核心和集成 |
| [**#frontend**](https://discord.com/channels/330944238910963714/1475552784278360176) | 前端 |
| [**#operating-system**](https://discord.com/channels/330944238910963714/1475552965954900018) | Home Assistant OS，以及 Supervisor |
| [**#apple-apps**](https://discord.com/channels/330944238910963714/1481713628553019392) | Apple 应用 |
| [**#designers**](https://discord.com/channels/330944238910963714/1463606665311158284) | 设计 |
| [**#product-and-ux**](https://discord.com/channels/330944238910963714/1475553148847526123) | 产品和用户体验讨论 |
| [**#user-researchers**](https://discord.com/channels/330944238910963714/1518940566576959618) | 用户研究 |

| [**#language-leaders**](https://discord.com/channels/330944238910963714/1257022942961991781) | 语言主管 |

服务器上的一些地方对所有贡献者开放：- [公开构建](https://discord.com/channels/330944238910963714/1257022408385237072) 是贡献者的公告频道。关注它以了解项目的动态。
- [一般编码支持](https://discord.com/channels/330944238910963714/1257019582112334014) 是当你在代码上遇到困难时提问的地方。
- [项目论坛](https://discord.com/channels/330944238910963714/1346914401508392980) 用于长时间运行的项目，以及团队正在冲刺的较大主题。

本站的频道链接会直接打开对应频道。只有在你[加入服务器](https://www.home-assistant.io/join-chat/)后才能使用。

一些区域也有自己的主题帖，比如伴侣应用。[上表](/start/where-we-talk#by-area)列出了它们。

一些有帮助的习惯：- 直接提出你的问题，并提供足够的上下文以便回答。像“有人能帮忙吗？”这种问题得到的答案通常比具体问题少。
- Discord 是聊天，聊天内容会被滚动掉。任何影响决策的重要内容都应放在 GitHub 上，这样可以保持可查找。
- 不要直接@某人以请求审核。请参阅 [pull requests 和审核](/start/pull-requests)。

## 社区论坛 {#the-community-forum}
[社区论坛](https://community.home-assistant.io/) 是用户互相帮助的地方：设置、自动化和设备。它也是一个无需编写代码就能贡献的好地方。回答问题是你可以做的最有价值的事情之一。请参阅 [社区](/community)。

本页介绍了贡献者协作的场所。想了解 Home Assistant 社区聚集的所有地方，如 Reddit、Facebook、聚会和地区社区？请参阅 [社区所在之处](/community/reference/channels)，或访问 home-assistant.io 上的 [社区页面](https://www.home-assistant.io/community/)。

## GitHub {#github}
所有代码、文档和决策都存放在 [GitHub](https://github.com/home-assistant)。不同类型的交流在那里的不同地方进行。

### 问题 {#issues}
问题是针对漏洞的：即某些功能未按预期工作。每个代码库都有自己的问题追踪器，所以请在代码所在的位置报告问题。[报告漏洞](/start/report-a-bug) 可以帮助你选择代码库，并解释表单的内容以及在报告之后会发生什么。

问题不用于支持问题或功能想法。问题表单会指引你到正确的位置：支持问题请参考 [帮助页面](https://www.home-assistant.io/help/)，功能请求则用于提交想法。

### 功能请求 {#feature-requests}
新的创意请提交到 GitHub 讨论中的 [功能请求](https://github.com/home-assistant/feature-requests/discussions) 。请先搜索，并在现有请求上投票，而不是新开重复请求。选择最合适的类别，比如 **仪表板与卡片** 或 **iOS 与 macOS**。说明你想要解决的问题，而不仅仅是解决方案。其他用户会投票和讨论，产品团队会根据受欢迎的请求来制定 [路线图](/roadmap/how-it-works)。

## 架构讨论 {#architecture-discussions}
关于 Home Assistant 架构的问题，例如新类型的实体或所有集成的规则，请在 [架构仓库](https://github.com/home-assistant/architecture/discussions) 中开始。[架构决策如何制定](/architecture/decisions) 解释了讨论如何变成决策。

### pull request {#pull-requests}
一旦你正在进行更改，关于它的讨论就会在 pull request 中进行。有关该更改的问题、审查意见和决策都保存在那里。

## 语言 {#language}
问题、pull request和关于GitHub的讨论都是用英语进行的，以便每个人都能跟上。Home Assistant Core 甚至有一个机器人会标记用其他语言写的问题。它不需要完美。如果英语不是你的母语，使用工具来帮助语法或翻译是可以的：[AI 政策](/start/ai-policy#non-native-english-speakers)解释了相关内容。

## 友善对待他人 {#be-kind}
[行为准则](/start/code-of-conduct)在这些地方都是适用的。如果你看到不合适的内容，可以使用该平台的举报或标记功能，或发送电子邮件至该页面上的地址。
