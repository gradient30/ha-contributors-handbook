# 我们的原则 {#our-principles}
Home Assistant 每天都会做很多决定：在评审中、在讨论中、在接下来要开发的内容上。大多数决定都可以追溯到几个核心价值观。了解这些价值观可以帮助你理解为什么评审者会要求修改，也可以帮助你自己做出同样的判断。

## 开放家庭 {#the-open-home}
Home Assistant 是 [Open Home Foundation](/start/organization) 的一部分，它代表智能家居中的三个价值观：

- **隐私**：你的家属于你自己。Home Assistant 本地运行，关于你家的数据会留在本地，除非你选择其他方式。云端是一个选择，而非必须。
- **选择**：你可以选择任何品牌的设备，并随意组合。没有供应商可以限制你的选择。
- **可持续性**：智能家居应该能够多年持续使用，而不是在公司退出后停止工作。

每个领域以自己的方式应用这些价值观。[架构原则](/architecture/principles) 解释了它们对代码的意义，[设计原则](/design/principles) 说明了它们对界面的意义。

## 我们如何协作 {#how-we-work-together}
#

## 公开透明 {#in-the-open}
代码、讨论和决策都在公共场合进行，在GitHub和公共频道里。任何人都可以阅读，也可以参与。当你在私人聊天中做出决定时，请把结果写下来，让其他人能够看到。

#

## 用户优先 {#the-user-comes-first}
Home Assistant 管理着数百万个家庭。人们依赖它来控制灯光、暖气和警报。这就是为什么影响现有设置的更改会格外谨慎，也为什么审查者可能会要求你保留一些你本想删除的功能。

#

## 质量优先于数量 {#quality-over-quantity}
项目宁愿少做但做好。这就是为什么审查可能看起来严格，也为什么 pull request 有时需要经过几轮。绝不是针对个人：这是为了让 Home Assistant 对每个人都能正常工作。

### 小步骤 {#small-steps}
一个小而集中的改变更容易理解、审查和合并。如有疑问，请将其拆分。[pull request和审查](/start/pull-requests) 解释了原因。

### 尊重他人的时间 {#respect-for-peoples-time}
许多贡献者在他们的空闲时间提供帮助，而审阅者的时间有限。要让时间发挥作用：在分享之前先测试你的工作，填写模板，并理解你提交的内容。[AI政策](/start/ai-policy)也源于相同的理念。

#

## 人人欢迎 {#everyone-is-welcome}
你无需成为专家才能做出贡献，也不需要掌握所有知识才能提问。[行为准则](/start/code-of-conduct)规定了我们在任何场合互相对待的方式。

## Home Assistant 的风格 {#how-home-assistant-sounds}
Home Assistant 也有自己的性格：热情、坦率、支持、慷慨、独立。它体现在界面、文档以及我们相互交流的方式中。[性格](/brand/personality)描述了每一项特质。
