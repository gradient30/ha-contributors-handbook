# 程序 {#programs}
除了日常社区，Open Home Foundation 还运行两个项目，将 Home Assistant 与项目外的人和公司联系起来。

## 创作者网络 {#creator-network}
[创作者网络](https://creators.home-assistant.io/) 是一个内容创作者群体，他们定期制作关于 Home Assistant 的内容：教程、产品评测以及他们项目的展示，发布在 YouTube、TikTok、Instagram 和其他平台上。

### 会员权益 {#what-members-get}
- 每月与 Home Assistant 团队在测试日举行会议，并有机会在新版本发布前提供反馈。
- 一个私人 Discord 频道，用于向开发团队提问和提供反馈。
- 可使用合作伙伴的产品，并可提前收到活动邀请。
- 免费获取最新官方 Home Assistant 硬件和 Nabu Casa 提供的 Home Assistant Link 订阅。

会员可以自由在其内容中分享对 Home Assistant 的真实观点和建设性反馈。会员资格免费，会员不会由 Open Home Foundation 获得报酬。他们可以通过自己的内容自由赚钱。

### 所需条件 {#what-it-takes}
创作者网络寻找在社区中拥有良好声誉、在其频道上拥有忠实粉丝、具备独特声音或知识，并且尊重他人的创作者，如[行为准则](/start/code-of-conduct)所述。

### 如何加入 {#how-to-join}
填写[申请表](https://forms.gle/R5z7yUS1tDJuio8N6)。申请每周审核一次，每个人都会收到回复，即使未被接受也会通知。

## 支持 Home Assistant {#works-with-home-assistant}
[支持 Home Assistant](https://works-with.home-assistant.io/) 是一个针对设备制造商的项目。参与该项目的产品经过 Open Home Foundation 测试，确保能够良好地与 Home Assistant 配合使用，并且其制造商承诺保持其正常工作。该项目强调设备的本地化、隐私性和安全性，并且注重耐用性。

对于社区而言，这个项目意味着一件事：[认证产品列表](https://works-with.home-assistant.io/certified-products/) 中的产品已知能够良好地与 Home Assistant 配合使用。

该项目面向制造商。如果你为制造商工作，或知道有制造商应该加入，请联系 [partner@openhomefoundation.org](mailto:partner@openhomefoundation.org)。

## 不是一个程序，但很接近 {#not-a-program-but-close}
- [社区日](https://www.openhomefoundation.org/community-day/)：一天的全球线下聚会，首次于2026年举办。详见 [主持聚会](/community/guides/meetups)。
- 设备数据库：Home Assistant 用户可以分享他们设备的匿名数据，以建立一个开放的数据库，了解设备在真实家庭中的表现。详见 [数据](/data)。
