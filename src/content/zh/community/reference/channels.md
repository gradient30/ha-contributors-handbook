# 社区居住的地方 {#where-the-community-lives}
Home Assistant 社区分布在几个地方。每个地方都有自己的优势和版主。[行为准则](https://www.home-assistant.io/code_of_conduct/) 在所有地方都适用。

## 社区论坛 {#community-forum}
[社区论坛](https://community.home-assistant.io/) 是获取帮助的最大也是运行时间最长的地方。问题和答案会保留并且易于搜索，因此一个已解决的话题可以多年帮助他人。论坛也有用于分享项目、蓝图和社区指南的分类，以及一个 **社交** 板块，用于发布线下聚会信息。

用于需要一些时间的问题、分享你建造的内容，以及任何别人以后可能需要找到的内容。

## Discord {#discord}
[Home Assistant Discord 服务器](https://www.home-assistant.io/join-chat)用于实时交流。它快速且非正式，非常适合快速提问或聊天。贡献者也会使用它：有用于开发和设计的频道，还有一个供测试下一个版本的人的 [**#beta**](https://discord.com/channels/330944238910963714/427516175237382144) 频道。

在 Discord 上说的话以后很难再找到。当你解决了其他人可能会遇到的问题时，考虑也把它发布在论坛上。

## Reddit {#reddit}
[r/homeassistant](https://www.reddit.com/r/homeassistant/) 子版块是很多人分享他们的设置、仪表盘和故事，以及寻求建议的地方。它由自己的版主管理，有自己的规则。

## Facebook {#facebook}
[Home Assistant Facebook 页面](https://www.facebook.com/homeassistantio) 分享新闻。还有一个 [Facebook 群组](https://www.facebook.com/groups/HomeAssistant/)，人们可以在这里寻求和提供帮助。

## 社交媒体 {#social-media}
官方账号分享新闻、发布信息以及社区亮点。查看 [社交媒体帮助](/community/guides/social-media) 获取列表。

## 通讯 {#newsletter}
[Open Home Foundation 通讯](https://newsletter.openhomefoundation.org/) 将 Home Assistant 及基金会的其他项目的新闻发送到你的邮箱。

## 聚会和活动 {#meetups-and-events}
本地聚会列在 [Luma 上的 Home Assistant 聚会日历](https://luma.com/homeassistant) 和 [社区页面](https://www.home-assistant.io/community/) 的地图上。参见 [举办聚会](/community/guides/meetups) 。

## 区域社区 {#regional-communities}
还有其他语言和地区的社区。[社区页面](https://www.home-assistant.io/community/) 列出了团队所知道的社区（并非完整列表），例如讲法语的论坛、讲德语的Discord 服务器和论坛，以及澳大利亚和新西兰、日本、挪威等地的群组。你的社区没列上吗？请发送邮件至 [community@openhomefoundation.org](mailto:community@openhomefoundation.org)。

## GitHub {#github}
GitHub 是代码和文档所在的地方，也是报告错误的地方。它不是一个支持渠道：关于使用 Home Assistant 的问题应该在论坛或 Discord 提出。功能请求应提交到 [功能请求讨论区](https://github.com/home-assistant/feature-requests/discussions)，而不是提交到问题追踪器。
