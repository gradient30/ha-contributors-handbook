# 同步日志 {#updates}

官网文档每次变动后，这里**单独记一笔**：改了什么、中文站在 Web 的哪一页。点进每一行就能跳到对应译本。

对照源：

- [llms.txt](https://contributors.home-assistant.io/llms.txt)
- [sitemap-0.xml](https://contributors.home-assistant.io/sitemap-0.xml)
- 各页 Markdown（路径加 `index.md`，例如 [start/index.md](https://contributors.home-assistant.io/start/index.md)）
- 源仓库 [home-assistant/contributors.home-assistant.io](https://github.com/home-assistant/contributors.home-assistant.io)

指纹表见 [对照表](/docs/sitemap)。仓库每 6 小时用 GitHub Actions 拉 sitemap 与各页 Markdown 哈希；有变动才回写同步日志并标出中文站路径。仅更新指纹时，不会把尚未重译的页面写成已经对齐。
