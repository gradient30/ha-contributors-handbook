# 提供品牌资产 {#provide-brand-assets}

此是铜法. 在`quality_scale.yaml`中,它被称为`brands`.

该集成像其图标和标志一样,在[品牌存储器](https://github.com/home-assistant/brands)中拥有其品牌资产.

## 为什么这很重要 {#why-it-matters}

用户在读取其名称之前很早就用其标志识别一个集成:在集成列表,设置对话框,以及文档的集成页面中. 遵循相同要求的资产保持所有整合的一致性,使每个整合都易于发现。

## 怎么办 {#what-to-do}

在品牌寄存器上打开 pull request 在 [`core_integrations/`](https://github.com/home-assistant/brands/tree/master/core_integrations) 中添加您集成的图像, 在以其域名命名的文件夹中 。 [品牌存储库的README](https://github.com/home-assistant/brands/blob/master/README.md) 列出您需要的文件、 大小和图像要求 。 早点做:您在核心的整合 pull request 当其品牌已经存在时, 更容易审查 。

## 如何检查 {#how-it-is-checked}

已检阅.

## 例外 {#exceptions}

这一规则没有例外。
