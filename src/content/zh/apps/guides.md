# 应用指南 {#app-guides}
每个指南涵盖一个任务。它们基于 [你的第一个应用](/apps/first-app) 和 [构建一个真实应用](/apps/build-a-real-app)，所以如果你还没做过，请先完成那些。

## 构建 {#build}
- [构建容器镜像](/apps/guides/dockerfile)：基础镜像、Bashio、构建参数和标签。
- [使用 S6 overlay 运行服务](/apps/guides/s6-overlay)：一次性和长期运行服务、依赖、完成脚本及环境。
- [添加选项](/apps/guides/options)：让用户配置你的应用。
- [访问硬件和主机](/apps/guides/hardware)：串口、USB、GPIO、音频和主机命名空间。

## 连接 {#connect}
- [与 Home Assistant 和 Supervisor 通信](/apps/guides/communication)：内部网络和 API。
- [通过 ingress 添加网页界面](/apps/guides/ingress)：在 Home Assistant 中显示你的应用。
- [共享服务并发现集成](/apps/guides/services-discovery)：MQTT、MySQL 以及服务发现。

## 发布应用 {#ship}
- [测试你的应用](/apps/guides/testing)：在你的电脑和真实设备上。
- [保护你的应用](/apps/guides/security)：AppArmor、API 角色和身份验证。
- [展示你的应用](/apps/guides/presentation)：用户在应用商店中看到的内容。
- [发布你的应用](/apps/guides/publishing)：图片、版本和发布。
- [创建并共享代码库](/apps/guides/repository)：用户可以在这里找到你的应用。
