# 安全参考 {#security-reference}

本节的页面是用来查找事物的. 如何使用它们, 请从 [指南](/security/guides) 开始 。

- [安全阖门](/security/reference/helpers): Core 的每个助手和前端的证书,编辑,管理员访问,webhoks,路径和不可信内容.
- [自动安全检查](/security/reference/checks):检查代码、依赖性和工作流程以及运行地点的工具。
- [过去的建议](/security/reference/advisories):每一次公开的咨询,按种类分组,有出错和教训.
