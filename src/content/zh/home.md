# Home Assistant 贡献者手册 {#home}

这是 [Home Assistant 贡献者文档](https://contributors.home-assistant.io/) 的**非官方**简体中文阅读站。原文由 Home Assistant 与 Open Home Foundation 维护，介绍如何以代码、设计、文档、翻译和社区工作的方式参与项目。

本站按官网的分区组织，路径与官网保持一致（例如官网 `/start/github/` 对应本站 `/start/github`）。命令、产品名、仓库名、代码和 API 标识保留英文。本期未翻译官方博客，入口见 [博客（官网）](/docs/blog)。

常用入口：

- [开始贡献](/start) — 项目如何运作，以及如何完成第一次贡献
- [同步日志](/docs/updates) — 每次对照官网后的记录
- [对照表](/docs/sitemap) — 每页指纹与中文站位置
- [本站架构](/docs/architecture-site) — 阅读器与发布方式
