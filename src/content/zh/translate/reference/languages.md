# 语文准则 {#language-guidelines}

多数语言提供了几种表达相同观点的方法. 为了保持语言的一致性,其翻译人员就几种选择达成一致. 这些协定以它们所讲的语言列出,因为它们是为讲当地语言的人写的。

你确实是没有语言,你是否与其他翻译达成协议? 确实是个小问题

## 德国 {#deutsch}

- 维尔德森。 Verwende in den übersetzungen "du", nicht das formelle "Sie". 維爾文德在"杜","迪","尼赫特·达斯"中译作"西".
- Achte auf den richtigen Imperativ:"Gib mir das Wasser",尼赫特语"Gebe mir das Wasser". Der [哥们](https://www.duden.de/sprachwissen/sprachratgeber/Bildung-des-Imperativs) erklärt die Regeln. (原始内容存档于2018-03-09).
