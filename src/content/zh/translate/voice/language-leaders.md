# 语文领导人 {#language-leaders}

Assist应该用他们自己的语言来理解他们, 并很好地理解他们。 为了不断提高每种语言的质量,语言有语言领袖:照顾自己语言的母语。

## 语言领袖做什么 {#what-language-leaders-do}

- ** 审查对其语言的每一改动。 ** 他们被通知每个 pull request 触摸语言的文件夹, 他们决定它是否合并 。
- ** 保证质量。 ** 他们检查句子是否正确,自然,并与其他语言一致. 句子滑过错误的东西, 或者根本不匹配。
- ** 措辞保持一致。 ** 他们决定正式或非正式地址等选择,决定共同事物所用的词语.

语言领袖拥有其语言的[`sentences/`](https://github.com/OHF-Voice/intents/tree/main/sentences),[`responses/`](https://github.com/OHF-Voice/intents/tree/main/responses),[`tests/`](https://github.com/OHF-Voice/intents/tree/main/tests),[`rules/`](https://github.com/OHF-Voice/intents/tree/main/rules)和[`lists/`](https://github.com/OHF-Voice/intents/tree/main/lists)文件夹. 他们不需要别人的批准来改变他们。

## 谁是领导者 {#who-the-leaders-are}

每种语言的首字母在 `leaders` 下在 [`languages.yaml`](https://github.com/OHF-Voice/intents/blob/main/languages.yaml) 中列出, 并带有它们的 GitHub 用户名 。 [`CODEOWNERS`](https://github.com/OHF-Voice/intents/blob/main/CODEOWNERS) 文件是从该列表生成的, 而该列表是如何生成 GitHub 知道该请谁审查 您也可以在 [支持的语言](/translate/voice/languages) 的表格中找到它们 。

## 成为语言领袖 {#become-a-language-leader}

任何人都可以申请,如果:

- 是语言的母语
- 给意图存储器至少做了两个 pull request 。
- 帮助审查 pull request 语言。

要应用,请在 [意图讨论](https://github.com/OHF-Voice/intents/discussions) 中开始一个话题, 或者在 Home Assistant [Discord 服务器](https://www.home-assistant.io/join-chat) 上询问 [发展中国家**](https://discord.com/channels/330944238910963714/554842238073700352) 。

有些语言还没有领先者. 如果你是其中之一,那是你的机会:贡献、检讨别人所开的,并申请。

## 失去角色 {#losing-the-role}

语言领袖是语言的守门人. 当领导者不活动时, 对语言的贡献会等待 。 当领导者接受低质量变化时,Assist停止正确理解人.
