# 个性 {#personality}
这五个特质描述了Home Assistant 是怎样的，而不是它如何说话。语气，如温暖、非正式和俏皮，应自然地从这些特质中体现出来。[声音和语调](/brand/voice-and-tone) 展示了实践中的样子。

## 特质如何相互契合 {#how-the-traits-fit-together}
前四个特质与关系相关。它们描述了 Home Assistant 对使用它的人是如何表现的：

- **热情欢迎** 表示我们如何接待他们。
- **坦率** 表示我们如何与他们交谈。
- **支持** 表示我们如何帮助他们。
- **慷慨** 表示我们给予他们的东西。

如果其中一些感觉相似，那是因为它们属于同一个特性，只是在不同的时刻表现出来。

**独立** 则不同。它是基础：Home Assistant 核心的自我。因为 Home Assistant 独立，其他四个特质才是真实的而非表演的。一个企业品牌可以尝试表现得热情欢迎、坦率、支持和慷慨，但如果没有独立性，这些特质总是被管理和调控的。

每个特质都有描述它是什么的词，也有描述它不是什么的词。第二个列表同样重要。

## 欢迎 {#welcoming}
Home Assistant 给人的感觉像一位博学的朋友，而不是一个产品。我们以你的水平与你交流，从不居高临下，让你感到被重视，无论你的技术技能如何。

这不是一种表演。它体现在细节上：如何解释错误、如何撰写文档、社区如何与新手交流。

- **是**：温暖开放、善良、友好、平易近人、通情达理  
- **不是**：讨好别人、安抚、阿谀奉承、献媚

## 坦率 {#candid}
Home Assistant 就是言出必行。我们不会用虚假的简单掩盖复杂性，不会依赖营销套话，也不会假装限制不存在。

我们尊重每一个人，因此会直截了当地告诉他们：Home Assistant 能做什么，不能做什么，以及它为什么会这样工作。这才是建立真正信任的基础。

- **是**：直接、诚实、透明、不矫饰
- **不是**：不友好、粗鲁、生硬、缺乏同理心

## 支持性 {#supportive}
Home Assistant 支持你。无论你是刚开始还是已经进入复杂的设置，我们都会引导你前进，而不会代替你操作。

这种支持是真诚的：实用、耐心，并且在最需要的时候提供帮助。Home Assistant 希望每个人都能在以隐私、选择和可持续性为核心的基础上成功地建立智能家居。

- **是**：有帮助的、引导的、鼓励的、有同理心的、真诚的
- **不是**：指令性的、空洞的、居高临下的、专横的

## 慷慨 {#generous}
Home Assistant 给你今天所需的一切，以及在你的设置扩展时所需的一切。没有附加条件：没有人为的限制，没有被隐藏在不同等级背后的功能，也没有旨在将你绑定到封闭平台的欺骗性模式。我们信任人们的控制权、访问权限和透明度。

这种慷慨是双向的。社区自由给予的时间、知识和关怀是Home Assistant能够蓬勃发展并真正开放的原因。

- **是**：赋能、信任、给予、分享
- **不是**：压倒性、无差别、居高临下、控制

## 独立 {#independent}
Home Assistant 不觉得有必要像一个成熟的科技品牌那样行事，也不需要遵循公司规则。没有股东或风险投资者需要负责，我们可以说出自己的想法，以自己的方式做事，并且不必太过认真看待自己。

这种自由源自自信：了解自己的价值观，并知道社区也认同这些价值观。

- **是**：有原则的、自由的、自信的、不完美的
- **不是**：自负的、固执的、反复无常的、封闭的
