# 名称和标志 {#name-and-logo}
名称和标志是品牌中最显眼的部分。本页介绍了如何书写名称、标志的作用以及哪些内容需要获得许可。

## 写下名称 {#write-the-name}
- **完整写出“Home Assistant”**，H 和 A 都要大写，中间有一个空格。不要写成“HA”、“HASS”或“Home-Assist”。适用于所有地方：文档、界面、博客文章以及本网站。
- **不要使用旧名称。** “Hass.io”现在只是Home Assistant，“HassOS”是Home Assistant Operating System。[home-assistant.io](https://github.com/home-assistant/home-assistant.io) 的自动检查会标记这两个。
- **不要翻译它。** 这个名称在所有语言中都保持为“Home Assistant”。请参阅[翻译规则](/translate/reference/rules)。

完整的软件套件称为Home Assistant。它的主要软件，Python应用程序，称为Home Assistant Core。这个命名始于2020年1月，当时品牌进行了调整，以便项目的各个部分更容易区分。

名称有时会变更。Home Assistant Cloud在2026年10月更名为Home Assistant Link。在代码中，它仍然是`cloud`集成。

## Open Home Foundation {#the-open-home-foundation}
Home Assistant 归 [Open Home Foundation](/glossary/open-home-foundation) 所有，该机构是非盈利组织。[home-assistant.io](https://www.home-assistant.io/) 的页脚是这样写的：“Home Assistant 是 Open Home Foundation 的一个项目。”

该基金会的商业合作伙伴，如 [Nabu Casa](/glossary/nabu-casa) 和 Apollo Automation，被允许创建可以授权使用 Open Home Foundation 品牌的产品。基金会的 [结构页面](https://www.openhomefoundation.org/structure/) 解释了其工作原理。

## 商标和许可 {#trademark-and-permission}
该标志是Open Home Foundation的商标和财产。未经基金会书面许可，不得用于商业用途。商业用途是指用于营销或推广待售产品、软件或服务的任何行为。如需申请，请发邮件至 [partner@openhomefoundation.org](mailto:partner@openhomefoundation.org)。

home-assistant.io 的 [服务条款](https://www.home-assistant.io/tos/) 将Home Assistant名称和标志列为商标，并声明使用该网站并不赋予你使用这些商标的权利。

是否运营有关Home Assistant的粉丝账号、群组或频道？请在其名称或描述中明确表示它非官方，以避免被误认为官方账号。详情参见 [社交媒体帮助](/community/guides/social-media)。

### 兼容 Home Assistant {#works-with-home-assistant}
通过 [Works with Home Assistant](https://works-with.home-assistant.io/) 认证的设备制造商拥有自己的一套 [徽章和品牌指南](https://works-with.home-assistant.io/resources/badge-and-brand-guidelines/)。这些指南仅适用于认证合作伙伴。例如，合作伙伴可以说某设备是“通过 Works with Home Assistant 计划认证的”，但不能说它是“Home Assistant 推荐”或“Home Assistant 产品”。

## 标志 {#the-logo}
标志是带天线的蓝色房子。每个部分都有其含义：

![The Home Assistant logo: a blue house with a white antenna inside it, next to the words Home Assistant in dark text](/_astro/logo.BTSG4HRx_ZeOTrK.webp)

- **蓝色** 给人稳定和必不可少的感觉。明亮的天蓝色让人感到愉快、清澈且无云。
- **房子** 代表家，简化为最具标志性的形状：一个带斜屋顶的直角房子，没有山花板或烟囱。
- **天线** 是之前标志中最容易识别的部分。有些人将其视为一棵树、一组节点或一块电路板。它代表智能、互联并且常青的技术。

从[资源库](https://github.com/OpenHomeFoundation/brand-assets/tree/main/home-assistant/logo)下载标志的所有版本。

## 布局 {#layout}
![The four layout variants: the logomark with the wordmark in a horizontal layout, the logomark only, the logomark with the wordmark in a vertical layout, and a vertical layout with a smaller logomark](/_astro/logo-layout-variants.BnywapBj_ApVUl.webp)

标志有四种布局：

- **文字标志，横向**：默认布局。它提供最清晰的上下文，因此在需要介绍Home Assistant时使用它。
- **图形标志**：仅使用房屋图案，适用于已经明确标识为Home Assistant的场合，比如在应用程序内部。图形标志可以单独使用，但文字标志永远不能没有图形标志。
- **文字标志，纵向**：适用于纵横比低于4:3的空间，比如衬衫上的方形位置。
- **文字标志，纵向加小图形标志**：当Home Assistant出现在相关项目旁边时使用，比如在语音处理流程图中。

## 颜色和背景 {#color-and-background}
- **浅色背景**：使用彩色版本并配深色文字。这是默认设置。
- **深色背景**，如深色主题的页面：使用彩色版本并配浅色文字。
- **深色或摄影背景**：浅色单色版本也可使用。
- **浅色或摄影背景**：使用彩色版本，而非单色版本。
- **无可用颜色**，如印刷时：使用单色版本。

仅在黑色、白色及非双色调照片中使用此标志。

## 禁忌 {#donts}
- 不要将标志放入方形、彩色形状或其他任何容器中。唯一例外是当其他公司的市场要求时，例如 iOS 应用图标。
- 不要添加投影。如果标志在背景上难以辨认，请更改背景以获得更多对比。只有在不得已的情况下，才使用高度模糊的投影。
- 不要使用轮廓版本。该标志没有轮廓版本。请改用单色版本。

## 空间 {#space}
给标志留出空间。保持标志周围至少为标志高度四分之一的清晰区域。

## 动画 {#animation}
静态徽标是默认选项。仅在介绍时使用动画版本，例如视频开头或加载界面。

仅在用户预期会有声音的场景下使用带声音的版本，例如视频开头。切勿在界面中使用，如加载界面。不要重复播放动画。

## 小尺寸 {#small-sizes}
对于非常小的空间，有一些特别的小版本，大约为 16 x 16 dp：网站的 favicon、Android 上的通知，或 macOS 的菜单栏。

## 规则所在 {#where-the-rules-live}
本页面包含 Home Assistant 的徽标指南。它取代了 design.home-assistant.io 上的徽标页面。要提出更改建议，请在 [UX 设计讨论](https://github.com/OpenHomeFoundation/ux-design/discussions) 中开始讨论，或在 [此网站](https://github.com/home-assistant/contributors.home-assistant.io) 上打开 pull request。
