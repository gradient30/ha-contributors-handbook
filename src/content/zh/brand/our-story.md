# 我们的故事和价值观 {#our-story-and-values}
一个品牌不仅仅是一个标志和语气。Home Assistant的品牌源于项目所代表的理念。个性、声音和视觉设计都表达了同一个理念：属于居住者的智能家居。

## 开放之家 {#the-open-home}
开放之家是Home Assistant背后的智能家居愿景。它定义了项目每一个决策背后的核心价值。这些价值融入到建筑、许可、社区以及其他所有方面。

拥有Home Assistant的[Open Home Foundation](https://www.openhomefoundation.org/)用三个词来概括：隐私、选择和可持续性。

### 隐私 {#privacy}
你的家应该是你的安全空间：一个你可以做自己的地方，而不必为了避免算法对你的行为进行分类而有所不同。对于开放之家来说，隐私意味着设备在本地工作。没有其他人需要知道你何时开灯或调整恒温器。

产品可以提供云连接，但这应该是额外的，并且需要选择加入。

### 选择 {#choice}
你家中的设备会收集关于它们自身和周围环境的数据。这些都是你的数据。厂商不应该限制你访问这些数据，也不应该限制你的设备与家中其他设备的协作。

对于开放式家居来说，选择意味着设备通过本地 API 提供其数据。这可以避免厂商锁定，并让人们使用不同厂商的设备构建智能家居。

### 可持续性 {#sustainability}
科技公司擅长推出新产品。保持它们持续运行往往被放在次要位置：供应商停止支持某个设备，功能就会损坏，或者设备完全停止工作。家里设备越多，这个问题就越重要。没有人应该因为制造商停产而每隔几年就必须重新购买所有东西。

对于开放家庭来说，这意味着设备的设计和制造都是为了持续运作。不只是今年，而是未来十年。

## 品牌价值的含义 {#what-the-values-mean-for-the-brand}
这些价值观是品牌之所以具有特定声调的原因。一个将人们的隐私和选择放在首位的项目，也不能对他们指手画脚、隐瞒限制，或用言语束缚他们。这就是[个性](/brand/personality)的来源：友好、坦率、支持、慷慨和独立。

这些价值观还以各自的方式影响着项目的其他方面：

- [我们的原则](/start/principles)：价值观在我们协作方式中的体现
- [架构原则](/architecture/principles)：它们对代码的影响
- [设计原则](/design/principles)：它们对界面的影响

## Home Assistant 的来源- **2013**：Paulus Schoutsen 在九月开始将 Home Assistant 作为一个 Python 应用程序，并在十一月将其发布到 GitHub。 {#where-home-assistant-comes-from}
- **2017**：七月，Hass.io，一个带有 Supervisor 的托管操作系统，可以安装、备份和更新 Home Assistant，使其更容易在像 Raspberry Pi 这样的单板计算机上运行。十二月，[[@H14@@](https://www.home-assistant.io/blog/2017/12/17/introducing-home-assistant-cloud/)] 作为免费的公开测试版启动，Amazon Alexa 是其第一个服务。
- **2018**：四月，[Google Assistant support](https://www.home-assistant.io/blog/2018/04/24/launch-google-assistant-support/) 也随后发布，仍在免费测试版中。九月，Home Assistant 的创始人和核心贡献者创立了 Nabu Casa，从此 [运行 Home Assistant Cloud 作为订阅服务](https://www.home-assistant.io/blog/2018/09/17/thinking-big/)。
- **2019**：三月，Home Assistant Cloud 为你的 Home Assistant 添加了 [安全远程访问](https://www.home-assistant.io/blog/2019/03/20/release-90/)。

- **2020**：一月，名称发生变化，使各个部分更易区分。Python 应用程序变为 Home Assistant Core。包括OS 与 Supervisor 的完整套件是 Home Assistant。
- **2024**：Home Assistant 和其他项目转移到 Open Home Foundation，一个非营利组织。
- **2025**：所有在基金会项目上工作的人员从 Nabu Casa 转移到 Open Home Foundation。Nabu Casa 继续作为基金会的商业合作伙伴。
- **2026**：Home Assistant Cloud 被重命名为 [Home Assistant Link](https://www.home-assistant.io/blog/2026/10/02/big-tech-ruined-the-cloud-so-were-renaming-ours/)。

[项目是如何组织的](/start/organization) 说明了基金会、其合作伙伴和贡献者今天是如何协作的。
