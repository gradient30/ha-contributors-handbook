# 翻译 {#translations}

Home Assistant有64种语言,每一种语言都由使用它的人翻译. 当巴西、日本或芬兰的某个人首次打开Home Assistant时,他们看到的字是像你这样的志愿者写的。

你不需要知道如何编码帮助。 如果你是讲母语的人,你关心你的语言读写方式, 你拥有它需要的一切。

## 两个帮助的方法 {#two-ways-to-help}

Cameron. 翻译工作有两种,它们使用不同的工具:

- ** 界面文本** 是您在屏幕上读到的一切:菜单、设置、对话框、错误消息以及实体名称及其状态。 您在浏览器中翻译 [茸茸茸茸的 Home Assistant 上面的项目 Lokalise](/translate/first-contribution#1-pick-a-project) 。
- ** Voice 命令** 是您与 Assist 交谈时所理解的句子, 以及它给出的答案 。 他们住在GitHub上的YAML文件中,语言领袖为他们的语言审查变化. 见[声音](/translate/voice).

大多数人从界面文本开始. 需要几分钟的时间才能出发,而你翻译的舰只没有审查步骤,见[翻译如何返回](/translate/how-it-works#how-translations-get-back).

## 谁说话 {#who-to-talk-to}

- 关于特定字符串的问题? 请在 Lokalise 中留言 。 你语言的其他译者都看见了
- 缺少一种语言,还是想讨论翻译如何运作? 在 GitHub 上使用 [本地化讨论](https://github.com/home-assistant/frontend/discussions/categories/localization) 。
- 在听声音吗? [意图讨论](https://github.com/OHF-Voice/intents/discussions) 是地方, 您语言的语言领袖审查您的更改 。 语言领袖在[语文领导人**](https://discord.com/channels/330944238910963714/1257022942961991781)频道在[Home Assistant Discord](https://www.home-assistant.io/join-chat/)上见面.
