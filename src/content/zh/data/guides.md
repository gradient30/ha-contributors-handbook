# 数据指南 {#data-guides}
每个指南涵盖一个任务。前三个不需要编写代码，只需要一些好奇心。最后一个适用于集成开发者。

- [使用公共数据](/data/guides/public-data)：下载分析数据集，并创建你自己的图表。
- [探索你自己的数据](/data/guides/explore-your-data)：将 JupyterLab 连接到你的 Home Assistant 数据库，并运行你的第一个报告。
- [查询数据库](/data/guides/query-the-database)：州、事件和上下文的 SQL 查询示例。
- [集成中的分析](/data/guides/integration-analytics)：你的集成如何在分析中显示，以及如何将设备或实体排除在外。
