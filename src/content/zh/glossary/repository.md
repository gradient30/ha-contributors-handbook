# 仓库 {#repository}

- 还:储存库、雷波

将寄存器视为项目文件夹,并带有内存. Home Assistant的每个部分都有自己的:Home Assistant Core在`home-assistant/core`中,文档在`home-assistant/home-assistant.io`中,界面在`home-assistant/frontend`中. 每个寄存器都有自己的问题,pull requests, 和维护者.

新建到 GitHub ? 解释你在那里遇到的词

## 相关条件 {#related-terms}

- [叉](/glossary/fork) : 您自己的寄存器副本, 在您的 GitHub 账户上, 您在提议更改前会在此更改 。
- [处](/glossary/branch):一个寄存器中一个单独的一行变化,这样你就可以在不接触主版本的情况下进行一些工作.
- [雌性](/glossary/issue):关于GitHub的关于寄存器中一个问题的报告,像错误一样,人们可以讨论和跟踪.
- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
