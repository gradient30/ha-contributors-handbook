# 语言领袖 {#language-leader}

- 代码 : `leaders in languages.yaml`
- 此外:语文领导人

语言领袖决定是否将语言句子的修改合并,并保持语言的正确性和一致性. 它们列在`leaders` `languages.yaml` [超高频 -- -- 声音/意图](https://github.com/OHF-Voice/intents) 寄存器的 GitHub 下, 这就是 GitHub 知道该请谁审查 见[语文领导人](/translate/voice/language-leaders)。

## 相关条件 {#related-terms}

- [意图](/glossary/intent):声音命令意味着什么,就像打开一个区域的灯,需要细节来做.
- [Assist](/glossary/assist): Home Assistant的语音助理. 它把你说的话或者打字变成行动
