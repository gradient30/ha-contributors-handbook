# Home Assistant Link {#home-assistant-link}
- 代码 : `cloud`
- 原名:Home Assistant Cloud(旧名:别在新文本中使用)

[Nabu Casa](/glossary/nabu-casa) 运行 Home Assistant Link , 大部分订阅利润 资助 [Open Home Foundation](/glossary/open-home-foundation) 。 Home Assistant工作没有它: 链接添加额外内容, 如从任何地方到达你的家, 连接 Alexa 和 Google Assist NAME OF NAME OF TRANSLATORS NAME OF TRANSLATORS NAME OF TRANSLATORS TRANSLATORS TRANSLATORS TRANSLATORS TRANSLATIONT TRANSLANSLA TRANSLATILA TRANSLATILANSLANSLATILATILANSLATILATIONTA , 更快的语音对文本对 Assist。

它被称为Home Assistant Cloud直到2026年10月. 在Core中,`cloud`集成连接到它,而UI和集成仍然在各地使用旧名. 在文本中,说Home Assistant Link。

## 相关条件 {#related-terms}

- [Nabu Casa](/glossary/nabu-casa):Open Home Foundation的商业伙伴,以及Home Assistant产品和服务的官方提供者,如Home Assistant Link.
- [Open Home Foundation](/glossary/open-home-foundation):拥有Home Assistant和许多相关项目的非营利组织,并代表着智慧之家的隐私,选择和可持续性.
