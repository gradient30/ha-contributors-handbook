# 设计符号 {#design-token}

- 代码 : `--ha-*`
- 还有:设计标志,标志

托肯斯是CSS变量,如`--ha-space-4`. 当一切使用它们时,设计可以在一个地方改变,主题可以压倒它们.

## 相关条件 {#related-terms}

- [主题](/glossary/theme): 一套改变前端颜色和一些尺寸的 CSS 变量 。
- [前端](/glossary/frontend):用 Lit 和 TypeScript 建造的 Home Assistant 的网页界面, 位于家用辅助/ 前端寄存器中 。
