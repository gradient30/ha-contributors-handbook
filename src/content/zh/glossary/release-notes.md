# 的一点是 {#release-notes}

发行笔记在发行当天直播[博客 Home Assistant](https://www.home-assistant.io/blog/categories/core/). 在亮点旁边,它们有每个补丁释放的一节,有[向后兼容的更改](/glossary/backward-incompatible-change)的一节,以及所有更改的列表.

晴朗的反向变化的文字来自其pull request的描述. 这就是为什么pull request模板要求您为用户写它。 见[发行笔记和发行方](/releases/guides/release-notes).

## 相关条件 {#related-terms}

- [发布](/glossary/release): Home Assistant的新版本 。 每个月的第一个星期三都出场 中间放出补丁
- [向后兼容的更改](/glossary/backward-incompatible-change):一个需要用户或开发者改变自己侧面的东西的更改,比如他们的配置或他们的自定义集成.
- [补丁释放](/glossary/patch-release):带有修正的较小的释放,在每月释放之间出现,如2026.10.1。
- [贝塔](/glossary/beta):下一次发行的测试版,在发布前一周发布,这样人们就可以在每个人更新之前发现问题.
