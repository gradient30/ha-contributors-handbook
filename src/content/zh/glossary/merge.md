# 合并 {#merge}

- 又:合并,合并,合并冲突.

只有维护者才能合并 pull request 。 一旦合并,GitHub标记它 **Merged**. 接下来会发生什么取决于寄存器: `current` 分支上的文档的修补会由Home Assistant进行直播 。 io一旦站点重建,而代码的更改会随着下一次发布而传到人们身上.

当您的分支和基分支更改了同一文件的畸形行时,会发生合并冲突,因此Git无法自行合并. 必须有人选择要保存的版本. GitHub 可以在浏览器中解决简单的冲突, 在 pull request 上 ** 解决冲突 ** 。

## 相关条件 {#related-terms}

- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
- [维护者](/glossary/maintainer): 可以在寄存器中批准和合并pull request的捐献者 。
- [处](/glossary/branch):一个寄存器中一个单独的一行变化,这样你就可以在不接触主版本的情况下进行一些工作.
