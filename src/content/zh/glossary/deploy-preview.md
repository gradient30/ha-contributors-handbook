# 部署预览 {#deploy-preview}

- 又: 预览

文档 pull request 可以从一个机器人获得其部署预览的链接 。 评论家们用它来观察读者所希望的变化.

## 相关条件 {#related-terms}

- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
- [CI](/glossary/ci):连续整合:自动检查,如测试,linters,和类型检查,运行在每pull request上.
