# Fork（复刻）  {#fork}

- 还有:叉子,叉子

您不能直接更改 Home Assistant 仓库 。 相反,您更改了叉子,并打开 pull request 来提议更改为原版 。报表四十二

## 相关条件 {#related-terms}

- [仓库](/glossary/repository): GitHub上的一个项目: 其文件, 以及每次更改的完整历史 。
- [处](/glossary/branch):一个寄存器中一个单独的一行变化,这样你就可以在不接触主版本的情况下进行一些工作.
- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
