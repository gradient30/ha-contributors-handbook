# 雌性 {#issue}

- 另外:问题,GitHub问题,问题追踪器

每个存放处都有自己的问题。 在 Home Assistant 中, 问题为: 错误, 或错误的文档页 。 特性想法到 [特性请求讨论](https://github.com/orgs/home-assistant/discussions) , 支持对 [社区论坛](https://community.home-assistant.io/) 的问题 。 见[我们说话的地方](/start/where-we-talk).

与修复采取必要行动的问题不同, Home Assistant 岔向用户显示 。 这是一个[修理](/glossary/repair)。

## 相关条件 {#related-terms}

- 衲子 [仓库](/glossary/repository): GitHub上的一个项目: 其文件, 以及每次更改的完整历史 。
- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
- [修理](/glossary/repair):一个问题 Home Assistant 显示在修补下的用户, 需要怎么做, 像配置会停止工作 。
