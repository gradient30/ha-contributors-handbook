# 提交 {#commit}

- 代码 : `SHA`
- 还有: 承诺、承诺

Git记录谁做出了每一个承诺,什么时候,并给它一个独特的ID,即SHA或散列. pull request 是树枝上的一组承诺。 向该分支添加承诺更新 pull request 。

## 相关条件 {#related-terms}

- [处](/glossary/branch):一个寄存器中一个单独的一行变化,这样你就可以在不接触主版本的情况下进行一些工作.
- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
