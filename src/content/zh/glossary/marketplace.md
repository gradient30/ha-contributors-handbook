# 市场 {#marketplace}

- 代码:`marketplace`,`hacs.json`

市场是核心的`marketplace`集成,其面板为**Settings** > **Marketplace**. 它是[HACS](/glossary/hacs), 带入Home Assistant : 它显示相同的目录, 从每个寄存器读取相同的`hacs.json` 文件 。

它安装的东西是由社区制作和支持的,而不是Home Assistant项目. [蓝图](/glossary/blueprint) 不在市集中: 用户从链接导入它们 。 [采购地点](/marketplace)解释如何为它出版。

## 相关条件 {#related-terms}

- [HACS](/glossary/hacs): Home Assistant社区商店:安装社区制作的集成,卡片和主题的定制集成,直到2026.11年市场更换. 它的目录和工具还在继续。
- [之一就是自定义集成](/glossary/custom-integration):不是Home Assistant Core一部分的集成,由用户安装在`custom_components`文件夹中.
- [自定义卡](/glossary/custom-card):不是前端部分的卡,由用户从JavaScript文件中加载.
- [主题](/glossary/theme): 一套改变前端颜色和一些尺寸的 CSS 变量 。
