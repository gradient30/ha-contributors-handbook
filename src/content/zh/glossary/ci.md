# CI {#ci}
- 代码 : `GitHub Actions`
- 另外:持续整合、检查

A pull request 只有在检查通过时才能合并 。准时,大多数检查也会在自己的电脑上运行,这样就可以在推前解决问题.

## 相关条件 {#related-terms}

- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
