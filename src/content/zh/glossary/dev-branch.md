# Dev 分支 {#dev-branch}

- 代码 : `dev`
- 又曰:夜卧,夜卧

`dev`分支有最新的代码, 和夜建由它制造。 被释放的生物在另一个分支上,比如`master`在Home Assistant Core中.汝可使用 `main` 和 Android app 来开发一些寄存器 。

关于Home Assistant的文件。 io工作方式不同:`current`是读者现在所看到的,`next`为下一次发行收集文档.

## 相关条件 {#related-terms}

- [发布](/glossary/release): Home Assistant的新版本 。 每个月的第一个星期三都出场 中间放出补丁
- [调用请求](/glossary/pull-request):在GitHub上请求将一个更改合并到一个寄存器中,在它进入之前要经过审查.
