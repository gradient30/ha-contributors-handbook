# 社区 {#community}
Home Assistant 是由其社区构建的，而其中很大一部分工作并不是编写代码。人们在 [论坛](https://community.home-assistant.io/) 回答问题，在 [Discord](https://www.home-assistant.io/join-chat/) 帮助他人调试自动化，在 Reddit 上分享他们的作品，或者在自己的城市组织线下聚会。这也是一种贡献，其重要性与任何 pull request 一样。

如果你想帮助他人充分利用 Home Assistant、保持我们的空间友好、或者把人们聚集在一起，那么这个区域就是为你准备的。

刚加入社区？home-assistant.io 上的 [社区页面](https://www.home-assistant.io/community/) 是每个 Home Assistant 用户的前门：可以找到人、附近的聚会、社区日，以及新闻简报。这个区域是关于在你加入后如何提供帮助。

## 帮助的方式 {#ways-to-help}
- **回答问题。** 有人卡在你上个月已经解决的问题上。你的答案可以为他们节省数小时。
- **欢迎新成员。** 友好的首次回复决定了他们是否会留下来。
- **保持社区健康。** 举报不合适的内容，帮助版主保持讨论的正轨。
- **分享和创作。** 展示你制作的内容，写教程，或者制作关于Home Assistant的视频。
- **面对面交流。** 参加或举办本地聚会。

## 与谁联系 {#who-to-talk-to}
- 关于社区的问题或建议？请发送电子邮件给Open Home Foundation的社区团队：[community@openhomefoundation.org](mailto:community@openhomefoundation.org)。
- 发现不安全行为或违反行为准则？请使用平台的举报功能，或发送电子邮件至 [safety@home-assistant.io](mailto:safety@home-assistant.io)。参见 [报告问题](/community/guides/reporting)。
