# 颜色选择器 {#color-picker}
实时演示 `ha-hs-color-picker`。

> 本页含交互式演示，阅读器中保留示例标记。完整可操作演示请看[官网原文](/design/components/color-picker)。

```html
<ha-hs-color-picker value="[32, 0.6]" style="width: 240px; height: 240px"></ha-hs-color-picker>
```

## 概述 {#overview}
颜色选择器是一个圆形的颜色轮。角度选择色相，距离中心的远近选择饱和度：中间为白色，边缘为纯色。用户可以拖动标记，也可以点击轮盘上的某个点直接跳到那里。

你可以在支持颜色的灯的“更多信息”对话框中找到它。在那里，它与其他几个控件一起放置：

- 一个小滴管按钮，用于打开浏览器或操作系统的原生颜色选择器，适合需要输入精确颜色的人。
- 用于调整颜色亮度和白色通道的滑块（适用于具有这些功能的灯）。颜色轮会跟随这些滑块，因此它显示的是灯实际生成的颜色。

## 何时使用 {#when-to-use}
使用色轮的情况：

- 根据视觉选择颜色，例如光的颜色。它快速且适合触控操作。

不要使用色轮的情况：

- 单独输入精确颜色。色轮不够精确。当精确数值很重要时，应在旁边提供另一种输入方式，就像“更多信息”对话框中通过原生颜色选择器所做的那样。
- 必须通过键盘可达到的颜色，而没有其他输入方式在旁边。色轮只能响应指针操作。

## 结构 {#anatomy}
1. **色轮**：带有所有色调的圆形画布，从中心的白色到边缘的完整颜色
2. **标记**：一个填充所选颜色的圆圈，有一个白色轮廓和阴影。当没有数值时，它会被隐藏。

## 变体 {#variants}
色轮没有变体。变化的是它的绘制方式。

### 亮度和白色通道 {#brightness-and-white-channels}
色轮以全亮度绘制颜色。它可以整体调暗，以匹配人们为颜色选择的亮度。

对于带白色通道的灯光，例如单白通道，或者冷白与暖白组合，色轮会将白色混入其颜色，以显示灯光效果。

`ha-hs-color-picker` 的实时演示。同样的色轮在半亮度下，并混入白色通道。

```html
<ha-hs-color-picker value="[32, 0.6]" data-props='{"colorBrightness": 128}' style="width: 200px; height: 200px"></ha-hs-color-picker>
<ha-hs-color-picker value="[32, 0.6]" wv="160" style="width: 200px; height: 200px"></ha-hs-color-picker>
```

这些只会改变色轮的外观。所选数值仍然是色调和饱和度。

## 行为 {#behavior}
- **拖动**：当有人拖动时，标记会变大，以便在指针下保持可见。使用鼠标或手写笔时，它会放大到原来的1.5倍。在触摸屏上，它会放大到原来的2.5倍，并稍微上移，以免被手指遮挡。
- **点击**：点击旋钮会将标记移动到该位置并选择颜色。
- **释放**：当拖动结束时，标记会动画回到正常大小，并选择颜色。当浏览器取消拖动时，标记会回到原来的位置。
- **禁用**：禁用的旋钮会忽略拖动和点击。它看起来与启用状态相同。
- **无值**：没有值时，标记会被隐藏。

旋钮没有悬停或焦点状态。

## 规格 {#specs}
轮盘填充其容器，标记会随之缩放。下面的标记尺寸是以轮盘坐标为单位的，默认宽度为400单位。

| 属性 | 数值 | 标记 |
| --- | --- | --- |
| 轮盘形状 | 圆形 | `--ha-border-radius-circle` (50%) |
| 标记半径 | 16 单位 | 无 |
| 标记轮廓 | 2 单位，白色 | 无 |
| 标记阴影 | 两个阴影：向下偏移 1 单位，模糊 2 单位，黑色 30%；向下偏移 1 单位，模糊 3 单位，黑色 15% | 无 |
| 拖动时标记缩放 | 鼠标或手写笔 1.5 倍，触摸 2.5 倍 | 无 |
| 触摸拖动时标记偏移 | 向上偏移轮盘尺寸的 1/16 | 无 |
| 标记动画 | 尺寸和颜色 100ms，位置 200ms，缓入缓出。拖动时关闭。 | 无 |
| 更多信息对话框中的尺寸 | 屏幕高度的 45%，在 200px 到 320px 之间 | 无 |

## 辅助功能 {#accessibility}
### 键盘 {#keyboard}
滚轮只对指针有反应：鼠标、触控笔或手指。它不会获取焦点，也没有键盘交互功能。将其与用户可以通过键盘访问的输入配对，例如更多信息对话框旁本机色彩选择器提供的输入。

### 可见性 {#visibility}
标记器是选中的颜色，带有白色轮廓和阴影，因此在色轮的浅色和深色部分都保持可见。

### 屏幕阅读器 {#screen-readers}
屏幕阅读器无法获取色轮上的任何信息。旁边的输入框是进入的方式。

### 代码中 {#in-the-code}
色轮是一个带有 SVG 标记器的画布。对于辅助技术，它没有角色、名称或数值。

## 代码中 {#in-code}
该元素是 `<ha-hs-color-picker>`。

```html
<ha-hs-color-picker value="[32, 0.6]"></ha-hs-color-picker>
```

色轮会填充其容器，因此需要设置大小。在更多信息对话框中，它是屏幕高度的 45%，在 200 到 320 像素之间。

```css
ha-hs-color-picker {
  height: 45vh;
  max-height: 320px;
  min-height: 200px;
}
```

### 属性 {#attributes}
- `value`：颜色，以数组形式表示色调（度数范围：`0` 到 `359`）和饱和度（`0` 到 `1`）。例如，`[32, 0.6]`。如果没有值，标记将被隐藏。
- `wv`：RGBW 灯的白色通道，范围从 `0` 到 `255`。
- `cw` 和 `ww`：RGBWW 灯的冷白和暖白通道，范围从 `0` 到 `255`。
- `disabled`：忽略拖动和点击。

### 属性 {#properties}
这些只能作为属性设置：

- `colorBrightness`：轮盘绘制时的亮度，从 `0` 到 `255`。默认值为 `255`。
- `minKelvin` 和 `maxKelvin`：光的色温范围。用于将冷白和暖白混合成颜色。
- `renderSize`：轮盘的分辨率，以像素为单位。默认值为 `400`。这不是屏幕上的大小。

### 事件 {#events}
- `value-changed`：颜色被选择，当有人松开或点击时触发。`detail.value` 是新的 `[hue, saturation]`。
- `cursor-moved`：拖动过程中标记移动。`detail.value` 是标记下的颜色，拖动结束时是 `undefined`。用于在拖动时预览颜色，而不必将每一步都发送到灯。

轮盘会移动其标记，但不会更新自己的 `value` 属性。从事件中读取新颜色。
